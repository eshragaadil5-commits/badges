# Mobile App Learning Portfolio 📱✨

Welcome to my Android development learning portfolio! This repository serves as a structured collection of Android Studio projects, exercises, and Kotlin fundamentals completed as part of the **Google Android Developer Learning**.

---

## 🛠️ Tech Stack & Tools

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Declarative UI)
* **IDE:** Android Studio
* **Version Control:** Git & GitHub
* **Learning Path:** Google Developer Training

## Overall Learning Reflection

Building this portfolio using Jetpack Compose gave me a strong foundation in modern Android development:
* **Declarative UI:** Writing layouts directly in Kotlin felt much more intuitive than traditional XML.
* **State Management:** Understanding how `remember` and `mutableStateOf` automatically update the UI was my biggest breakthrough.
* **Code Clarity:** Keeping composables short and focused made my code far easier to read and debug.
