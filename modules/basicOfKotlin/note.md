## Project Summary

basicOfKotlin covers fundamental syntax and core programming concepts in Kotlin through hands-on exercises from Google's Android Developer Training.

Functionality: Demonstrates basic arithmetic operations (addition and subtraction) by passing variables into custom functions and printing formatted results.

Key Concepts Learned:

Variable Declarations: Using read-only val variables for integer storage (firstNumber, secondNumber, thirdNumber).

Function Definition: Declaring custom functions (add, subtract) with explicit parameter types (Int) and return types (Int).

String Templates: Formatting clean terminal outputs using string interpolation ("$firstNumber + $secondNumber = $result").

## Personal Reflection

This module was straightforward and provided a clear refresher on basic Kotlin syntax.

The task was simple and quick to complete, making it easy to practice fundamental building blocks like function parameters, return values, and variable assignments. Writing clean, readable code at this basic level builds the right habits for structuring larger functions in future Android projects.
