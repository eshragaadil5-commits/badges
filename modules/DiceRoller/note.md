## Project Summary
DiceRoller is an interactive Android app built with Kotlin and Jetpack Compose following Google's Android Developer Training.

Functionality: Users tap a button to roll a 6-sided die, generating a random number (1–6) that dynamically updates the displayed dice image.

Key Concepts Learned:

Composable Functions & Layouts: Defining UI structures and layouts using Compositions.

Interactive UI: Creating clickable controls with the Button composable.

Resource Handling: Importing drawable resources and displaying images with the Image composable.

State & Memory: Storing objects in Composition memory using remember and triggering UI refreshes with mutableStateOf() observables.

## Personal Reflection

This lesson provided a clear and simple introduction to modern Android UI development.

The code was straightforward to follow and made essential concepts click—especially how remember holds data across recompositions and how mutableStateOf() automatically refreshes the UI when values change. It was a great, hands-on way to build confidence with interactive composables before tackling larger projects.
