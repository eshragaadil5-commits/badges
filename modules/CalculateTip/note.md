## Project Summary

CalculateTip is an interactive Android application built with Kotlin and Jetpack Compose as part of Google's Android Developer Training.

Functionality: Calculates custom tip amounts and total bill balances dynamically based on user input, bill total, and percentage selections.

Key Concepts Learned:

Compose UI Layouts: Building structured, accessible form controls using Column, TextField, Spacer, and Text.

State & Input Handling: Managing user input state with remember and mutableStateOf() to perform real-time calculation updates.

Budget & Math Logic: Formatting numerical inputs, handling currency strings, and applying conditional calculations dynamically.

UI Polish: Adjusting keyboard action types (e.g., KeyboardOptions for number entry) and aligning elements for a clean budget-calculator user experience.

## Personal Reflection

This project was a great practical lesson in handling real-time user input and dynamic UI updates in Android.

The code was straightforward and clean, making it easy to see how user inputs directly drive state changes in Jetpack Compose. Building a budget tool like a tip calculator helped reinforce how to process text fields, format numerical data, and update UI components on the fly without complex boilerplate code.
